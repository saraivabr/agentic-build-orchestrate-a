## Primeiros passos

Primeiro, rode o servidor de desenvolvimento:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador para ver o resultado.

Você pode começar a editar a página alterando `app/page.tsx`. A página atualiza automaticamente enquanto você edita o arquivo.
